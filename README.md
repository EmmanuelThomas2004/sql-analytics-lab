# SQL Business Challenges

A collection of practical SQL problems based on real-world business and data analytics scenarios.

The goal of this repository is to improve SQL problem-solving skills by working with questions that are commonly encountered in data analyst roles and interviews.

## 📌 What You'll Find

* Customer revenue analysis
* Employee salary analysis
* Monthly sales performance
* Customer activity analysis
* User engagement and consecutive-day analysis
* SQL window functions
* Aggregations and grouping
* Joins and subqueries
* CTEs
* Date and time analysis

## 🧩 Challenges

| #  | Business Problem                                      | Key SQL Concepts                       |
| -- | ----------------------------------------------------- | -------------------------------------- |
| 01 | Find the top 5 customers by completed-order revenue   | `GROUP BY`, `SUM`, `ORDER BY`, `LIMIT` |
| 02 | Find the second-highest salary in each department     | `DENSE_RANK`, `PARTITION BY`           |
| 03 | Calculate monthly revenue and month-over-month growth | `LAG`, Aggregation, Date Functions     |
| 04 | Find customers who have never placed an order         | `LEFT JOIN`, `NULL`                    |
| 05 | Find users active for at least 3 consecutive days     | `CTE`, `ROW_NUMBER`, Date Functions    |

## 🎯 Objective

This repository focuses on solving SQL problems from a **business perspective**, not just writing queries.

Each challenge starts with a business question and uses SQL to turn the question into a measurable result.

## 🛠️ SQL Skills

* SELECT & Filtering
* GROUP BY & Aggregations
* JOINs
* Subqueries
* CTEs
* Window Functions
* Ranking
* Date Functions
* Time-Series Analysis
* Business Metrics
